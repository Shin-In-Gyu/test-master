## 📋 [문제 1] 프로세스 생성과 `fork()` 반환값 추적 (코드 분석)

다음 C 코드를 보고 질문에 답하시오.

```c
#include <stdio.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

int main() {
    pid_t pid, pid1;

    pid = fork();

    if (pid < 0) {
        fprintf(stderr, "Fork Failed\n");
        return 1;
    }
    else if (pid == 0) {
        pid1 = getpid();
        printf("child: pid = %d\n", pid);
        printf("child: pid1 = %d\n", pid1);
    }
    else {
        wait(NULL);
        pid1 = getpid();
        printf("parent: pid = %d\n", pid);
        printf("parent: pid1 = %d\n", pid1);
    }
    return 0;
}
```

**[가정]**: 부모 프로세스의 실제 PID는 `2500`, 새로 생성된 자식 프로세스의 실제 PID는 `2501`이다.

**(1)** 표준 출력(stdout)에 출력되는 4줄의 내용을 순서대로 정확하게 적으시오.  
**(2)** 부모 프로세스의 `pid` 변수와 자식 프로세스의 `pid` 변수에 저장된 값이 서로 다른 이유를 `fork()` 시스템 콜의 반환 규칙 관점에서 기술하시오.

## 📋 [문제 7] 단방향 파이프(Ordinary Pipe) 코드 분석

다음은 UNIX 파이프를 이용한 프로세스 간 통신(IPC) 코드이다.

```c
#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <sys/types.h>

#define BUFFER_SIZE 30
#define READ_END 0
#define WRITE_END 1

#include <stdio.h>
#include <string.h>
#include <unistd.h>
#include <sys/types.h>
#include <sys/wait.h>

#define BUFFER_SIZE 30
#define READ_END 0
#define WRITE_END 1

int main() {
    char write_msg[BUFFER_SIZE] = "Operating System Exam";
    char read_msg[BUFFER_SIZE];
    int fd[2];
    pid_t pid;

    if (pipe(fd) == -1) return 1;

    pid = fork();

    if (pid > 0) { /* 부모 프로세스: 송신자 */
        close(fd[READ_END]);
        write(fd[WRITE_END], write_msg, strlen(write_msg) + 1);
        close(fd[WRITE_END]); /* (A) */
        wait(NULL);
    }
    else { /* 자식 프로세스: 수신자 */
        close(fd[WRITE_END]);
        read(fd[READ_END], read_msg, BUFFER_SIZE); /* (B) */
        printf("Received: %s\n", read_msg);
        close(fd[READ_END]);
    }
    return 0;
}
```

**(1)** 배열 인덱스 `fd[0]`과 `fd[1]`의 역할을 각각 쓰시오.  
**(2)** 코드의 `(A)`와 `(B)`에서 사용하지 않는 파이프 끝단을 `close()` 함수로 즉시 닫아주는 이유를 프로세스 동기화(EOF 감지) 관점에서 서술하시오.

**(2)** 각 프로세스($P_1, P_2, P_3$)의 **반환 시간(Turnaround Time)**을 각각 구하시오.  
**(3)** 시스템의 **평균 대기 시간(Average Waiting Time)**을 구하시오.  
**(4)** 만약 시간 할당량 $q$가 $25\text{ ms}$로 설정된다면 이 스케줄링은 어떤 스케줄링 알고리즘과 사실상 동일해지는지 명칭을 쓰시오.

### [문제 14 정답 및 해설]
**(1) 간트 차트 (Gantt Chart)**:
```text
| P1 | P2 | P3 | P2 | P4 |   P1   |
0    2    4    5    7    11       16
```
- $t=0$: $P_1(7)$ 실행
- $t=2$: $P_2(4)$ 도착. $P_1$ 남은 시간 $5 > 4 \rightarrow P_2$가 선점!
- $t=4$: $P_3(1)$ 도착. $P_2$ 남은 시간 $2 > 1 \rightarrow P_3$가 선점!
- $t=5$: $P_3$ 완료. $P_4(4)$ 도착. 남은 작업: $P_2(2), P_4(4), P_1(5) \rightarrow P_2$ 실행
- $t=7$: $P_2$ 완료. 남은 작업: $P_4(4), P_1(5) \rightarrow P_4$ 실행
- $t=11$: $P_4$ 완료. 남은 작업: $P_1(5) \rightarrow P_1$ 실행
- $t=16$: $P_1$ 완료

**(2) 대기 시간 ($\text{대기시간} = \text{완료시각} - \text{도착시각} - \text{버스트시간}$)**:
- $P_1 = 16 - 0 - 7 = \mathbf{9\text{ ms}}$ (구간별: $(0-0) + (11-2) = 9$)
- $P_2 = 7 - 2 - 4 = \mathbf{1\text{ ms}}$ (구간별: $(2-2) + (5-4) = 1$)
- $P_3 = 5 - 4 - 1 = \mathbf{0\text{ ms}}$
- $P_4 = 11 - 5 - 4 = \mathbf{2\text{ ms}}$

**(3) 평균 대기 시간**:
$$\frac{9 + 1 + 0 + 2}{4} = \frac{12}{4} = \mathbf{3.0\text{ ms}}$$

### [문제 15 정답 및 해설]
**(1) 간트 차트 (Time Quantum $q=4$)**:
```text
| P1 (4) | P2 (4) | P3 (2) |         P1 (16)         |
0        4        8        10                        26
```
- $t=0\sim4$: $P_1$이 4ms 실행 후 16ms 남고 큐 tail로 이동.
- $t=4\sim8$: $P_2$가 4ms 실행 후 완료.
- $t=8\sim10$: $P_3$가 2ms 실행 후 완료 ($q=4$보다 짧으므로 자발적 CPU 반납).
- $t=10\sim26$: 큐에 혼자 남은 $P_1$이 나머지 16ms를 모두 수행하여 완료.

**(2) 반환 시간 ($\text{완료 시각} - \text{도착 시각(0)}$)**:
- $P_1 = 26 - 0 = \mathbf{26\text{ ms}}$
- $P_2 = 8 - 0 = \mathbf{8\text{ ms}}$
- $P_3 = 10 - 0 = \mathbf{10\text{ ms}}$

**(3) 평균 대기 시간 ($\text{대기시간} = \text{반환시간} - \text{버스트시간}$)**:
- $P_1 = 26 - 20 = 6\text{ ms}$
- $P_2 = 8 - 4 = 4\text{ ms}$
- $P_3 = 10 - 2 = 8\text{ ms}$
- 평균 대기 시간 = $\frac{6 + 4 + 8}{3} = \frac{18}{3} = \mathbf{6.0\text{ ms}}$

**(4)** 시간 할당량이 모든 프로세스의 버스트 시간보다 큰 경우, 프로세스가 인터럽트 없이 한 번에 끝나므로 **FCFS (선입선출, First-Come First-Served)** 스케줄링과 동일해진다.
