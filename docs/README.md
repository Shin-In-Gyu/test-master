# 📚 전공 시험 대비 원본 문서 아카이브 (Exam Docs Archive)

이 디렉터리는 각 과목별 **시험 정리 원본 마크다운(`.md`) 및 실전 문제 자료**를 체계적으로 보관하는 아카이브입니다.

## 💡 새 과목 문서 추가 규칙
새로운 과목을 추가할 때는 `docs/과목ID/` 폴더를 생성하고, 학습 흐름에 맞게 번호(`01_`, `02_`...)를 매겨 저장하면 됩니다.
웹앱과 연동하려면 `data/_template.js`를 활용하여 `data/과목ID.js`를 생성하세요.
