+ 새 과목 추가 및 확장 가이드

이 시스템은 다른 과목(자료구조, 알고리즘, 데이터베이스 등)을 무제한 확장할 수 있도록 모듈형 데이터베이스 아키텍처로 설계되어 있습니다.
data/ 폴더에 새 과목 자바스크립트 파일(예: data/database.js)을 생성하고 index.html 하단에 <script src="data/database.js"></script>만 추가하면 드롭다운과 탭이 자동 생성됩니다.

1. 새 과목 데이터 작성 규격 (data/database.js):
window.CONCEPT_DATABASE = window.CONCEPT_DATABASE || {}; window.EXAM_DATABASE = window.EXAM_DATABASE || {}; // 개념 총정리 데이터 window.CONCEPT_DATABASE.db = { id: "db", title: "데이터베이스", filterChips: [{ id: "all", label: "전체보기" }, { id: "rel", label: "관계대수" }], html: `<section id="rel" class="concept-section">...</section>` }; // 모의고사 데이터 (객관식, 단답형, 계산형, 서술형 지원) window.EXAM_DATABASE.db = { title: "데이터베이스", maxScore: 100, exams: [{ id: "exam1", name: "제1회 데이터베이스 모의고사", tag: "객관식 + 단답 + 서술", questions: [ { id: 1, type: "short", score: 5, origin: "1장 ACID", text: "트랜잭션의 4대 특성 중 ...", answers: ["원자성", "Atomicity"] } ] }] };
