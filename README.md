# 🎓 EXAM MASTER DOSSIER
> **대학 시험 완벽대비 전공 기밀 총정리 & 실전 모의고사 평가 플랫폼**

`EXAM MASTER DOSSIER`는 전공 시험 기간 동안 방대한 강의 내용, 교수님 육성 출제 힌트, 실습 코드, 모의고사를 압도적인 가독성으로 학습하고 자가 진단할 수 있도록 설계된 **영구 소장용 모듈형 수험 웹 플랫폼**입니다.

## ✨ 핵심 기능 (Features)

1. **Zero-Build & 즉각적인 휴대성**: npm, Webpack 등 빌드 도구 없이 `index.html` 더블클릭만으로 모든 디바이스에서 즉각 구동.
2. **네이티브 마크다운 & LaTeX 수식 지원**: `marked.js` 및 `KaTeX` 연동으로 HTML 태그 작성 없이 마크다운(`.md`)으로 손쉬운 과목 추가.
3. **교수님 출제 프로파일링 (Professor Profiling)**: 교수님별 킬러 감점 룰 및 출제 성향을 최상단 배너에 자동 렌더링.
4. **자가 테스트 모드 (Active Recall)**: 원클릭 정답 마스킹 및 카드 클릭 시 정답/해설 확인 기능.
5. **실전 모의고사 자동 채점**: 객관식, 단답형(복수 정답 허용), 계산형, 서술형(채점 키워드) 실시간 자동 채점 및 100점 만점 게이지.
6. **A4 치트시트 인쇄 최적화**: `@media print` 전용 스타일을 통해 시험장 지참용 종이 출력 지원.

---

## 🚀 새 과목 추가 방법 (2분 완성)

1. `data/_template.js` 파일을 복사하여 `data/과목ID.js` (예: `data/algorithm.js`)를 생성합니다.
2. `data/과목ID.js` 내부의 마크다운 요약과 모의고사 문항을 작성합니다.
3. `index.html` 하단에 `<script src="data/과목ID.js"></script>` 한 줄을 추가합니다.
4. 웹앱을 실행하면 상단 드롭다운과 탭이 **자동으로 생성**됩니다.
